Frequently asked questions

Why don't the images in my document show?

macOS lets Minimal.md read only the files you open. For images stored next to your document, a bar appears at the bottom of the window — choose the folder there to grant access. You can review and revoke access at any time in Settings → Privacy. Images on the web are never loaded: Minimal.md makes no network connections.

Quick Look doesn't show my Markdown files rendered.

Open Minimal.md once after installing it, so macOS registers its Quick Look extension. If previews still show plain text, check that Minimal.md is turned on in System Settings → General → Login Items & Extensions → Quick Look.

How do I make Minimal.md my default Markdown app?

Open Settings → General and choose Set as Default. macOS asks you to confirm the change. You can switch back to your previous app from the same place.

Can I edit my files with Minimal.md?

No — Minimal.md is a viewer and never changes your files. To edit a document, open it in your editor. To take its text elsewhere, use Edit → Copy as Markdown.

Part of my document shows as raw Markdown or HTML.

That's deliberate: anything Minimal.md can't render faithfully is shown as its source rather than hidden. If you think it should be rendered, please send us the document.

Which languages does Minimal.md support?

English, French, German, Italian, Russian and Spanish, following the language set for your Mac.
