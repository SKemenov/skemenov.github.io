How to join

Three steps, on your Mac.

  1. Install TestFlight from the Mac App Store.
  2. Open the public beta link on your Mac.
  3. Accept the invitation and install MinimalMD. TestFlight keeps it up to date with each new build.

What to test

In this build.

✦

New in this build

  • Minimal.md is now MinimalMD. Check that Finder, Open With and Settings → General show the new name.
  • Open in your Markdown editor: the toolbar button or File → Open in… (⌘E) hands the document to your editor. Pick another one in Settings → General, or keep the system default. With no editor installed, the button reads Choose an Editor….
  • Copy Document as Markdown from the toolbar or Edit menu (⇧⌘C), then paste it somewhere.
  • The first time you open the app, a short guide shows you around. Open it again from the Help menu, and check that it doesn’t come back on the next launch.
  • Live reload follows every app that writes the file, including AI agents and command-line tools: try appending to an open file from Terminal.
  • The sidebar keeps the current heading in view as you scroll a long document.
  • Text size shortcuts (⌘+, ⌘−, ⌘0) work after every change, including at the smallest and largest sizes.
  • The File menu has no editing commands, and the View and Edit menus have no doubled dividers.
  • On macOS 27 Golden Gate, the toolbar looks right. On macOS 15 Sequoia, please try the app there too.
  • VoiceOver keeps its place in long documents and reads table columns more clearly.
✓

Please also try

  • Open your own .md files — READMEs, notes, documentation. Does anything look wrong or go missing?
  • Press the Space bar on a Markdown file in Finder. Does Quick Look show it rendered?
  • Keep a document open while an agent or a script edits it, or while you move it to another folder and back. Does the window follow every change?
  • Use the table of contents in the sidebar and the heading navigation in the toolbar.
  • Open a document with local images. If they’re hidden, grant access to the folder from the bar at the bottom of the window, then revoke it in Settings → Privacy.
  • Set MinimalMD as the default app for Markdown in Settings → General.
  • Change the text size, and switch between light and dark mode.
  • If your Mac uses French, German, Italian, Russian or Spanish, check the app in that language.
