Markdown

Everything in the document.

GitHub-flavored Markdown, rendered natively.

Text

  • Bold, italic and strikethrough
  • Inline code
  • Links
  • Line breaks

Structure

  • Headings, levels 1–6
  • Bulleted and numbered lists, nested
  • Task lists
  • Block quotes
  • Horizontal rules

Tables and code

  • Tables with column alignment
  • Bold, italic, code and links in cells
  • Code blocks in the system monospaced font

Extras

  • YAML front matter, shown as a table
  • Local images, linked images too
  • HTML: centered text, sized images, simple tables
  • HTML comments stay hidden

Anything Minimal.md doesn't render is shown as its source — never dropped.
