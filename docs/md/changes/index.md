# What’s new in MinimalMD

Every release and what changed in it, newest first.
{: .lead}

## 1.2.0

November 16, 2026
{: .meta}

NEW
{: .eyebrow}

- Minimal.md is now MinimalMD: same app, a name that no longer reads like a file
- Open the document in your Markdown editor right from the toolbar
- Choose which editor in Settings, or keep the system default
- Copy Document as Markdown from the toolbar
- The first time you open the app, a short guide shows you around. Open it again any time from the Help menu

FIXED
{: .eyebrow}

- Live reload now follows every app that writes the file, including AI agents and command-line tools
- The sidebar keeps the current heading in view as you scroll
- The File menu no longer lists editing commands
- No more doubled dividers in the View and Edit menus
- Text size shortcuts work after every change
- The toolbar looks right on macOS 27
- VoiceOver keeps its place in long documents
- VoiceOver reads table columns more clearly

## 1.1.0

October 13, 2026
{: .meta}

NEW
{: .eyebrow}

- Plans and reports from AI agents update live as they’re written
- Now supports macOS 15.6 Sequoia and later
- New languages: Spanish (Latin America) and French (Canada)

FIXED
{: .eyebrow}

- More room above headings makes long documents easier to read and navigate
- New windows fit the document’s height
- Quick Look shows local images right after installing
- VoiceOver reads Settings more clearly
- Menu titles are capitalized correctly in every language
- The toolbar and Settings look right on macOS 15
