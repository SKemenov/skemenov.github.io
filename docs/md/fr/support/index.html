Questions fréquentes

Où obtenir Minimal.md ?

Minimal.md est gratuit sur le Mac App Store et nécessite macOS 15.6 Sequoia ou ultérieur.

Pourquoi les images de mon document ne s’affichent-elles pas ?

macOS ne laisse Minimal.md lire que les fichiers que vous ouvrez. Pour les images enregistrées à côté de votre document, une barre apparaît en bas de la fenêtre : choisissez-y le dossier pour autoriser l’accès. Vous pouvez vérifier et retirer l’accès à tout moment dans Réglages → Confidentialité. Les images du web ne sont jamais chargées : Minimal.md n’établit aucune connexion réseau.

Coup d’œil n’affiche pas mes fichiers Markdown en rendu.

Ouvrez Minimal.md une fois après l’avoir installé, pour que macOS enregistre son extension Coup d’œil. Si les aperçus affichent toujours du texte brut, vérifiez que Minimal.md est activé dans Réglages Système → Général → Ouverture et extensions → Coup d’œil.

Comment faire de Minimal.md mon app Markdown par défaut ?

Ouvrez Réglages → Général et choisissez Définir par défaut. macOS vous demande de confirmer la modification.

Comment rendre les fichiers Markdown à mon app précédente ?

Ouvrez Réglages → Général et choisissez Rétablir à côté de « Revenir à … ». Cette ligne apparaît tant que Minimal.md est l’app par défaut et que votre app précédente est encore installée. Sinon, sélectionnez un fichier Markdown dans le Finder, choisissez Fichier → Lire les informations, choisissez une app sous Ouvrir avec, puis cliquez sur Tout modifier.

Puis-je modifier mes fichiers avec Minimal.md ?

Non : Minimal.md est un lecteur et ne modifie jamais vos fichiers. Pour modifier un document, ouvrez-le dans votre éditeur. Pour en reprendre le texte ailleurs, utilisez Édition → Copier le document au format Markdown.

Une partie de mon document s’affiche en Markdown ou HTML brut.

C’est voulu : ce que Minimal.md ne peut pas rendre fidèlement s’affiche en code source au lieu d’être masqué. Si vous pensez qu’il devrait être rendu, envoyez-nous le document. Voir ce que Minimal.md affiche en rendu.

Quelles langues Minimal.md prend-il en charge ?

Allemand, anglais, espagnol, français, italien et russe, selon la langue choisie pour votre Mac. Vous avez repéré une erreur de traduction ou voulez Minimal.md dans votre langue ? Dites-le-nous.

Qu’est-ce qui a changé dans la dernière version ?

Chaque version et ses modifications figurent dans le journal des modifications (en anglais), de la plus récente à la plus ancienne.
