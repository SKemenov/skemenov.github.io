Confidentialité

Politique de confidentialité de Minimal.md

Minimal.md ne collecte aucune donnée. Vos documents restent sur votre Mac.

Dernière mise à jour : 1er octobre 2026 · Traduction de la version originale en anglais, qui fait foi en cas de divergence.

Ce que Minimal.md collecte

Rien. Minimal.md n’a ni compte, ni analyse, ni publicité, ni suivi d’aucune sorte. Il n’établit aucune connexion réseau (ses propres réglages de sandbox ne le lui permettent pas), donc rien de ce que vous ouvrez ne peut quitter votre Mac par son intermédiaire. Les images hébergées sur le web ne sont jamais chargées.

Ce que Minimal.md lit

Uniquement les fichiers Markdown que vous ouvrez, et les dossiers que vous choisissez explicitement de partager pour que leurs images locales s’affichent. L’aperçu Coup d’œil lit le fichier que vous prévisualisez dans le Finder. Minimal.md n’écrit jamais dans vos fichiers.

Ce qui reste sur votre Mac

Vos réglages (comme la taille du texte et l’affichage des images locales) et la liste des dossiers que vous avez partagés sont stockés localement sur votre Mac, où l’app et son aperçu Coup d’œil peuvent les lire. Vous pouvez retirer l’accès aux dossiers à tout moment dans Réglages → Confidentialité. Supprimer l’app supprime ces données.

Apple

Si vous choisissez, dans les réglages de votre Mac, de partager les données d’analyse avec les développeurs d’apps, Apple peut transmettre des rapports de plantage anonymes concernant Minimal.md. Apple traite ces données selon sa propre politique de confidentialité ; Minimal.md n’y ajoute rien. Les bêta-testeurs sur TestFlight peuvent envoyer des commentaires et des captures d’écran via Apple : uniquement ce qu’ils choisissent d’envoyer.

Enfants

Minimal.md ne collecte aucune information auprès de quiconque, y compris les enfants.

Modifications

Si cette politique change, la nouvelle version sera publiée sur cette page avec une nouvelle date.
