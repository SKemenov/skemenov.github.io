Minimal.md
Markdown Support Privacy Beta

Markdown viewer & Quick Look

Open a Markdown file and just read it.

Minimal.md opens your .md files and shows them the way they were meant to be read — and it never changes them.

Free · Requires macOS 26 Tahoe or later · Supported Markdown

Features

No editor, no sync, no account.

Just the document, rendered natively with the system fonts, in light or dark mode.

¶

Read, don't edit

Minimal.md never writes to your files. Open Markdown from Finder or Open With, or make it your default Markdown app in Settings → General.

␣

Quick Look

Select a Markdown file in Finder and press the Space bar to read it rendered, without opening the app.

∅

Private by design

No network connections, no data collected, and remote images are never loaded. It reads only the files you open and the folders you share.

Screenshots

A closer look.

  1. Tables, task lists and code. GitHub-flavored Markdown, rendered natively: tables keep their alignment, task lists show their checkboxes, and fenced code stays monospaced.

  2. Looks the same in Quick Look. The Finder preview uses the app’s own renderer, so a document reads exactly as it does in Minimal.md.

  3. At home in light and dark. Documents follow your Mac’s appearance, with the system fonts and a text size you can adjust.

  4. Every shared folder in one place. Settings → Privacy lists each folder you’ve let Minimal.md read. Revoke any one of them, or all at once.
