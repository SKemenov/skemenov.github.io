Частые вопросы

Где взять Minimal.md?

Minimal.md бесплатно в Mac App Store и требует macOS 15.6 Sequoia или новее.

Почему не показываются изображения в моём документе?

macOS разрешает Minimal.md читать только открытые вами файлы. Для изображений рядом с документом внизу окна появляется панель — выберите там папку, чтобы предоставить доступ. Просмотреть и отозвать доступ можно в любой момент в Настройках → Конфиденциальность. Изображения из интернета никогда не загружаются: Minimal.md не устанавливает сетевых подключений.

Быстрый просмотр не отрисовывает мои файлы Markdown.

Откройте Minimal.md один раз после установки, чтобы macOS зарегистрировала его расширение Быстрого просмотра. Если просмотр по-прежнему показывает простой текст, проверьте, что Minimal.md включено в Системных настройках → Основные → Объекты входа и расширения → Быстрый просмотр.

Как сделать Minimal.md программой по умолчанию для Markdown?

Откройте Настройки → Основные и нажмите «Назначить по умолчанию». macOS попросит подтвердить изменение.

Как вернуть файлы Markdown прежней программе?

Откройте Настройки → Основные и нажмите «Восстановить» рядом с «Снова открывать файлы Markdown в программе …». Эта строка видна, пока Minimal.md назначено по умолчанию, а прежняя программа ещё установлена. Иначе выберите любой файл Markdown в Finder, выберите Файл → Свойства, укажите программу в разделе «Открывать в приложении» и нажмите «Изменить все».

Можно ли редактировать файлы в Minimal.md?

Нет: Minimal.md — приложение для чтения, оно никогда не меняет ваши файлы. Чтобы изменить документ, откройте его в своём редакторе. Чтобы перенести текст в другое место, выберите Правка → Скопировать документ как Markdown.

Часть документа показана как необработанный Markdown или HTML.

Так и задумано: всё, что Minimal.md не может отрисовать точно, показано исходным текстом, а не скрыто. Если считаете, что это нужно отрисовывать, пришлите нам документ. См. что отрисовывает Minimal.md.

Какие языки поддерживает Minimal.md?

Английский, испанский, итальянский, немецкий, русский и французский — в зависимости от языка вашего Mac. Нашли ошибку в переводе или хотите Minimal.md на своём языке? Напишите нам.

Что изменилось в последней версии?

Все версии и их изменения перечислены в списке изменений (на английском), начиная с новейшей.
