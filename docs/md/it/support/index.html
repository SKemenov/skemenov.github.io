Domande frequenti

Dove trovo Minimal.md?

Minimal.md è gratuita su Mac App Store e richiede macOS 15.6 Sequoia o versione successiva.

Perché le immagini del mio documento non vengono mostrate?

macOS consente a Minimal.md di leggere solo i file che apri. Per le immagini salvate accanto al documento, compare una barra in fondo alla finestra: scegli lì la cartella per consentire l’accesso. Puoi controllare e revocare l’accesso in qualsiasi momento in Impostazioni → Privacy. Le immagini sul web non vengono mai caricate: Minimal.md non effettua connessioni di rete.

Visualizzazione rapida non mostra i miei file Markdown resi.

Apri Minimal.md una volta dopo averla installata, così macOS registra la sua estensione di Visualizzazione rapida. Se le anteprime mostrano ancora testo semplice, verifica che Minimal.md sia attiva in Impostazioni di Sistema → Generali → Elementi login ed estensioni → Visualizzazione rapida.

Come rendo Minimal.md la mia app predefinita per Markdown?

Apri Impostazioni → Generali e scegli Imposta come predefinita. macOS ti chiede di confermare la modifica.

Come restituisco i file Markdown alla mia app precedente?

Apri Impostazioni → Generali e scegli Ripristina accanto a “Restituisci il ruolo a …”. Questa riga appare finché Minimal.md è l’app predefinita e la tua app precedente è ancora installata. Altrimenti, seleziona un file Markdown nel Finder, scegli Archivio → Ottieni informazioni, scegli un’app in Apri con e fai clic su Modifica tutto.

Posso modificare i miei file con Minimal.md?

No: Minimal.md è un lettore e non modifica mai i tuoi file. Per modificare un documento, aprilo nel tuo editor. Per portarne il testo altrove, usa Composizione → Copia documento come Markdown.

Parte del mio documento appare come Markdown o HTML grezzo.

È voluto: ciò che Minimal.md non può rendere fedelmente appare come sorgente invece di essere nascosto. Se pensi che debba essere reso, inviaci il documento. Vedi cosa visualizza Minimal.md.

Quali lingue supporta Minimal.md?

Francese, inglese, italiano, russo, spagnolo e tedesco, in base alla lingua impostata sul tuo Mac. Hai trovato un errore di traduzione o vuoi Minimal.md nella tua lingua? Faccelo sapere.

Cosa è cambiato nell’ultima versione?

Ogni versione e le sue modifiche sono elencate nel registro delle modifiche (in inglese), dalla più recente.
